NLP Analysis Platform

An interactive Natural Language Processing web platform built using Python, spaCy, NLTK, Pandas, Matplotlib and Gradio.

Features

- 🏷️ Named-Entity Recognition
- 🧩 Part-of-Speech Tagging
- 📊 POS Distribution
- 🔤 Lemmatization
- ✂️ Stemming
- 🧬 Morphological Analysis
- 🔗 Dependency Parsing

Technologies Used

- Python
- spaCy
- NLTK
- Pandas
- Matplotlib
- Gradio
- Jupyter Notebook
